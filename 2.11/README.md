# Задания 2.11 — Context API и продвинутые хуки

Реализованы Todo с раздельными Context для данных и dispatch и сохранением в localStorage, тема и авторизация через Context, корзина на `useReducer`, фильтрация с `useMemo`, мемоизированные элементы с `memo`/`useCallback`, поиск с `useDebounce` и хук `usePrevious`.

Запуск: `npm install`, затем `npm run dev`. Проверка сборки: `npm run build`.
