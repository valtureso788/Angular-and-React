# Задания 28.10 — localStorage и роутинг

Реализованы Todo с `useLocalStorage`, сохраняемый счётчик и тема, debounce-черновик, подтверждение сброса, блог с динамическими маршрутами, хлебные крошки профиля, защищённый `/admin`, фильтр пользователей в `?city=...` и 404.

Запуск: `npm install`, затем `npm run dev`. Проверка сборки: `npm run build`.
