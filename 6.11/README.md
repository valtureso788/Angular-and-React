# Задания 6.11 — ветвления в C++

Каждое упражнение находится в отдельном файле `exercise01.cpp`–`exercise15.cpp`.
Файлы независимы: скомпилируйте и запустите нужный, например:

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic exercise01.cpp -o exercise01
.\exercise01.exe
```

Для ввода десятичных чисел используйте точку. Упражнения решены отдельно,
чтобы в каждом явно использовать требуемую конструкцию ветвления.
