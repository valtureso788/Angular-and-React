# Финальный проект 9.11 — трекер задач

TypeScript SPA на React + Vite: React Router, TanStack Query, Context для избранного и темы, Zod + React Hook Form, `useLocalStorage`, `useMemo`/`useCallback`/`memo`, страницы обзора/задач/деталей/настроек/404. Список задач и операции используют JSONPlaceholder; избранное и тема сохраняются локально. Домашнее задание включает фильтр избранного `?filter=favorites`, очистку избранного и типизированный `EmptyState`. Выбран творческий вариант A: поиск с debounce 300 мс и мемоизированные карточки.

Запуск: `npm install`, затем `npm run dev`. Проверка типов и production-сборка: `npm run build`.
